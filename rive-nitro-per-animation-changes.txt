RIVE NITRO UPGRADE — PER-ANIMATION CODE CHANGES
Branch: chore/rive-nitro-migration
Packages: remove rive-react-native ^9.8.0
          add @rive-app/react-native 0.4.19
          react-native-nitro-modules 0.35.5 → 0.35.10

Common mechanical changes (almost every site):
  <Rive> → <RiveView>
  source={asset} → useRiveFile(asset) + file={riveFile}
  autoplay → autoPlay
  ref / onPlay gate → useRive() hybridRef + riveViewRef ready
  fireState(sm, name) → triggerInput(name)  (sm stays on stateMachineName prop)
  RNRiveError → RiveError (+ map type for perf hooks where needed)

No .riv binary files were edited in this upgrade — JS/API ports only
(except behavior approximations noted below).
