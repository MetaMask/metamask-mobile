5. Failure patterns

Shared no-metrics (likely app/flow)

  • Money Home · empty wallet
  • Money Home · imported wallet
  • Perps open position and close it
  • Rewards tab

These fail across vendors — treat as product/test issues, not provider ranking signal.

Provider-specific QG fails

  • Fresh SRP: fails on BrowserStack + both TestMu; Sauce Private & Cloud pass (~8s)
  • Cold → Login: fails BrowserStack + Sauce Private; Cloud / HE pass
  • Import SRP +50: Sauce Cloud only (15.77s QG fail vs ~3s elsewhere)
  • Account creation: Sauce Private only
  • Predict Deposit: BrowserStack QG fail; Sauce no metrics; TestMu passes (HE best at 9.3s)

6. Conclusions

  • TestMu HyperExecute remains the most reliable lane (18/23) and leads on Predict Deposit, Asset View, and Warm → Login.
  • Sauce Labs — especially Private — is now timing-competitive after Appium settings parity. On the shared pass set it has the best mean, and it is the only vendor that clears Fresh SRP (~8s).
  • BrowserStack often wins Seedless Apple and some balance/predict timers, but still carries Fresh SRP, Predict Deposit, and Cold → Login QG pressure.
  • Sauce Cloud matches Private on pass rate but is less predictable (Import SRP +50 blow-up, more no-metrics). Prefer Private over Cloud for stable benchmarking.
  • For fair vendor comparison: use the shared timed-pass set + Fresh SRP; ignore Money Home / Rewards / Perps open-close until they stop returning no metrics everywhere.
