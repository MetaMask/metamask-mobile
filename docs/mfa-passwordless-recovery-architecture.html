MFA passwordless recovery — suggested flows

Social-login users can Forgot password → Create a new password. Recovery setup runs automatically after the wallet unlocks (passkey only if needed; no verifier ID).

New user

Social login (create wallet) → Create password → [auto] Passkey enroll if needed → Seal Recovery Secret → Onboarding → Home
flowchart TD
  A["Social login: new wallet"] --> B["Create password"]
  B --> C["Wallet unlocked"]
  C --> D{"Recovery already set up?"}
  D -->|Yes| G["Continue onboarding"]
  D -->|No| E{"Passkey ready?"}
  E -->|Yes| F["Seal Recovery Secret"]
  E -->|No| H["OS passkey enroll"]
  H -->|Done| F
  H -->|Cancel| I["Skip setup, continue"]
  F -->|Success| G
  F -->|Fail soft| I
  G --> J["Home"]
  I --> J

Existing user

Social login / unlock → Password or biometrics → [auto] Passkey if vault not sealed → Seal Recovery Secret → Home
flowchart TD
  A["Social login: existing wallet"] --> B["Enter password or biometrics"]
  B --> C["Wallet unlocked"]
  C --> D{"Recovery already set up?"}
  D -->|Yes| G["Open wallet"]
  D -->|No| E{"Passkey ready?"}
  E -->|Yes| F["Seal Recovery Secret"]
  E -->|No| H["OS passkey prompt"]
  H -->|Done| F
  H -->|Cancel| I["Skip setup, open wallet"]
  F -->|Success| G
  F -->|Fail soft| I

Forgot password (both)

Forgot password → MFA if needed (AAL2 = “it’s you”) → Escrow passkey (release Recovery Secret) → Create password → Wallet
flowchart TD
  A["Forgot password"] --> B{"Recovery sealed?"}
  B -->|No| C["Cannot recover"]
  B -->|Yes| D{"AAL2 still valid?"}
  D -->|No| E["MFA verify"]
  E --> F["Hold AAL2"]
  D -->|Yes| F
  F --> G["Loader: Confirm with your passkey"]
  G --> H["Escrow passkey / prefetch Recovery Secret"]
  H --> I["Create password"]
  I --> J["Recover vault + unlock"]
  J --> K["Wallet"]

End-to-end

flowchart TD
  A["Social login"] --> B{"New or existing?"}
  B -->|New| C["Create password"]
  B -->|Existing| D["Unlock password / biometrics"]
  C --> E["Wallet unlocked"]
  D --> E
  E --> F["Auto recovery setup"]
  F --> G{"Already sealed?"}
  G -->|Yes| H["Home"]
  G -->|No| I["Passkey if needed"]
  I --> J["Seal Recovery Secret"]
  J --> H
  I -->|Cancel / fail| H
  H --> L["Later: Forgot password"]
  L --> M["MFA / AAL2"]
  M --> N["Escrow passkey"]
  N --> O["Create password"]
  O --> P["Wallet"]

Why two passkey moments on Forgot

┌─────────────────┐ ┌──────────────────────┐ ┌─────────────────┐ │ MFA / AAL2 │────▶│ Escrow passkey │────▶│ Create password │ │ identity verify │ │ read Recovery Secret │ │ set new password│ └─────────────────┘ └──────────────────────┘ └─────────────────┘ ↑ ↑ “Verify it’s you” “Release sealed secret”

AAL2 does not replace the escrow passkey with current Auth / Cubist APIs. Loader before Create password: Confirm with your passkey to recover your wallet.
