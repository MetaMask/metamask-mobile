MFA recovery flows

1) Setup — Recovery Secret when a 2FA factor is added

Money onboarding and Settings use the same flow. After any factor is added, recovery is set up on Cubist.

  • Passkey / social / SIWE: register those identifiers.
  • Email OTP / authenticator: link social + SIWE only (no email/TOTP Cubist identifier).
  • Existing email OTP users (Telegram cohort) must re-verify.
  • Ready gate: sealed seedless envelope — factors alone are not enough. 
flowchart TD
  A["2FA factor added
Money onboarding or Settings"] --> B{"Factor type?"}
  B -->|Passkey / social / SIWE| C["Register Cubist identifiers
incl. that factor"]
  B -->|Email OTP / authenticator| D["Link social + SIWE only"]
  C --> E["Create Recovery Secret"]
  D --> E
  E --> F["Seal on Cubist / TOPRF
envelope set"]
  F --> G["Recovery ready"]

  H{"envelope already set?"} -->|Yes| I["already_enabled"]
  H -->|No| A

2) Locked social login — MFA then password / biometrics

After social login (wallet locked): passkey first, then methods list (Password, Authenticator, SMS per design; email only for Telegram).

  • Biometrics available after rehydration: generate a random local password behind biometrics, then store it in the keychain. Never synced to global — the Recovery Secret replaces the password for recover. Next unlock: biometrics retrieves that local password from the keychain (no social re-login required).
  • No biometrics / Face ID declined: user verifies their existing global password (verify, not create). If it matches → fetchAllSecretData({ password }). No temporary local password on this path.
  • Enter password validations match the existing Login screen.
  • Forgot password → global reset flow (§3). Checks AAL2 first.

  B -->|Cancel / fail| C["Verify it's you

  B -->|Success| D["MFA success

  I --> H

§3"]

3) Forgot password — global reset

From Enter password → Forgot password. AAL2 checked first; then MFA if needed; Create password syncs local + global. 

flowchart TD
  A["Forgot password"] --> B{"AAL2 still valid?"}
  B -->|No| C["MFA verify"]
  C --> D{"Verified?"}
  B -->|Yes| E["Proceed"]
  D -->|Yes| E
  D -->|No| F["Retry / stay on verify"]

  E --> G{"Recovery sealed?"}
  G -->|No| H["Cannot recover"]
  G -->|Yes| I["Prefetch Recovery Secret
escrow passkey if needed"]
  I --> J["Create password"]
  J --> K["Set local + sync global"]
  K --> L["Restore vault → Home"]
