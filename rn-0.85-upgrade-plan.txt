================================================================================
RN 0.85 UPGRADE PLAN — LIBRARIES, CODE CHANGES, EXPO MIGRATIONS
================================================================================
Baseline: RN 0.83.6 + Expo SDK 55 + React 19.2.0 (New Arch, bridgeless)
Target:   RN 0.85.3 + Expo SDK 56 (expo ~56.0.15) + React 19.2.3
Verified: 2026-07-13 against RN 0.84/0.85 blogs + CHANGELOG, npm registry,
          Expo SDK 55/56 bundledNativeModules.json, and this repo's package.json.
Supersedes: rn-0.85-pre-upgrade-libraries.txt (2026-07-06/10 spike — corrections
          from that file are marked [FIXED] below).

Strategy: every item below lands as a GREEN PR on 0.83 FIRST. The final upgrade
PR only touches packages whose versions are interlocked with RN 0.85 / SDK 56.
RN 0.85 has NO legacy bridge/interop fallback at all — any lib still on legacy
arch must be replaced or fixed BEFORE upgrade day, there is no escape hatch.

CONTEXT (versions in the wild, 2026-07-13):
  RN latest = 0.85.3 (no 0.85.4; 0.86.0 out, 0.87.0-rc.0 exists)
  Expo npm `latest` = SDK 57 (RN 0.86, shipped 2026-06-30)
    -> PIN expo@sdk-56 dist-tag / ~56.0.15 to avoid accidental SDK 57 installs.

  effective (RN 0.84 floor). AUDIT CI RUNNER IMAGES NOW — lead time risk.

  the new API so the upgrade PR is a version-bump only.

  expo-router; our direct @react-navigation v6 usage is unaffected.
- iOS Expo modules layer rewritten (ObjC++ removed, Swift/C++ JSI interop) +
