DESCRIPTION
Land every dependency bump, native fix, and code change required before the
React Native 0.83.6 -> 0.85.3 core bump. Each item ships as its own PR and soaks
in `main`, so the eventual RN core bump is a version-only change with minimal risk.

WHY
- 0.85 enforces New Architecture (bridgeless) + Hermes V1; several libraries fail
  to build/link/run under it (legacy-arch APIs removed, TurboModule rewrites).
- Landing bumps incrementally isolates regressions and gives each change soak time.
